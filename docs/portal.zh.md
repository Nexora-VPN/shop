# 网页应用：门户与小程序

语言：[English](portal.md) · [فارسی](portal.fa.md) · [Русский](portal.ru.md) · **中文**

Shop 的客户只有一个网页应用，位于 `https://<shop>/app/`，它同时是两样东西：

- **网页门户**，可在任何浏览器中使用。当 Telegram 被封锁或机器人丢失时，它能让您的商店继续销售：客户用发送到其**邮箱**或**手机号**的验证码登录，或用**机器人**确认的验证码登录，然后像在机器人中一样购买、付款、续费，查看服务和用量。它可以安装到手机主屏幕上（PWA）。
- **小程序**，在 Telegram 内使用。一旦 Shop 的公开地址是 `https://`，机器人菜单就会显示 **打开商店**；Telegram 会自动让客户登录。在网页上购买过的客户只需关联一次邮箱或手机号（用验证码证明），就能看到同样的服务、钱包和订单。

请把 Shop 放在它自己的地址上——绝不要和面板放在一起——并启用 HTTPS，然后设为公开地址（`PUT /api/settings/payments`，`publicUrl`）。Telegram 只通过 HTTPS 打开小程序。

## 设置

安装时会询问 Shop 的**公开地址**、是否由 Shop 自行获取 **HTTPS 证书**（`https: acme`）以及**机器人令牌**——三项都是可选的，之后都可以修改。随后 Shop 的管理后台会显示一份检查清单，直到 Shop 可以销售为止：地址（从外部检查）；机器人（向 Telegram 检查，并把其菜单按钮设为小程序）；**您的 Telegram 作为管理员**——打开链接或扫描二维码并点击 Start；**凭证群组**——把机器人加入管理员群组，并在目标话题中发送 `/receipts`；银行卡；从面板套餐中选出的商品。任何地方都不需要输入 id。

使用 `https: acme` 时，公开地址的域名必须指向 Shop 所在的服务器，且该服务器的 443 端口必须空闲：Shop 自己在 443 上应答证书颁发机构的验证（TLS-ALPN-01），因此 80 端口上无需任何监听，证书也会自动续期。Shop 自己的端口（8095）仍为面板提供普通 HTTP。

使用 `https: self-signed` 时——以 IP 访问的地址，例如 `https://203.0.113.9:8443`，没有证书颁发机构会为其签发证书的域名——Shop 会生成自己的证书，并在地址所写的端口上应答。浏览器会提示一次警告；通信是加密的，**快速设置** 会显示证书指纹，供您与浏览器显示的指纹比对。Telegram 不会在此类地址上打开小程序，因此机器人不会提供小程序：客户使用机器人和浏览器中的网页应用。

## 邮件登录

您的 SMTP 服务器（`PUT /api/settings/email`）：

```json
{"host": "smtp.example.com", "port": 587, "username": "shop@example.com",
 "password": "…", "from": "shop@example.com", "security": "starttls"}
```

`security` 为 `starttls`（端口 587）、`tls`（端口 465）或 `none`（仅用于同一服务器上的中继）。验证码为六位数字，有效期十分钟，可尝试五次；每个地址十五分钟内最多收到三个验证码，每个 IP 每小时最多十个。

## 短信登录：通用协议

Shop 不指定任何短信服务。请通过一个小型中继把它接到您的服务上（`PUT /api/settings/sms`，`{"url": "https://relay.example/sms"}`——不填密钥时由 Shop 生成）：

```http
POST <url>
X-Nexora-Timestamp: 1790000000
X-Nexora-Signature: <hex HMAC-SHA256 of "1790000000.<body>" under the secret>
Content-Type: application/json

{"to": "+989121234567", "text": "Your shop sign-in code: 123456"}
```

消息发出后返回 2xx。签名与 Shop 调用您任何服务时的签名相同（参见[支付](payments.zh.md)）；请在中继中校验。号码以国际格式送达；输入为 `0912…` 的伊朗号码会变为 `+98912…`。

## 机器人登录

设置了机器人后，门户会提供 **通过 Telegram 机器人登录**：它打开 `t.me/<bot>?start=login_<code>`，客户点击 Start，确认后页面便自动登录。机器人会先询问——“有浏览器请求以 … 的身份登录您的账户”，并显示该浏览器的地址、设备和时间——只有点 **确认** 才会登录；点 **拒绝** 则作废该码。登录码五分钟内有效，并且只有请求它的那个浏览器会登录：把自己的链接发给客户的人什么也得不到。这需要能访问 Telegram——邮件和短信登录正是为无法访问时准备的。

验证码、登录和付款查询按客户端地址限制次数。如果商店位于终止 TLS 的反向代理之后，请在安装的 `.env` 中把 `NEXORA_OPT_TRUSTED_PROXIES` 设为代理的地址或网段（`127.0.0.1, 10.0.0.0/8`）：商店便从该代理的 `X-Forwarded-For` 读取客户端地址。留空（默认）则不信任任何转发头。

## 客户能做什么

我的订阅（带复制按钮和二维码的链接、用量、到期日、续费、加流量、用钱包支付的自动续费）、购买、付款——用卡转账并提交凭证照片、PDF 或流水号，或通过您的网关——钱包及充值、免费试用、折扣码和礼品码，以及推荐链接（[折扣码、礼品码和推荐](promotions.zh.md)）。它使用商店已开启的语言，每位客户用自己的语言，顶部有切换开关；新服务暂停时，或因面板没有余量而把订单款项退回钱包时，它也会告知客户。

# Nexora Shop

Официальное дополнение [Nexora](https://nexora-panel.org) для продажи тарифов панели: товары, заказы, кошелёк, оплата переводом с карты на карту и через шлюз, Telegram-бот, веб-приложение, промокоды и подарочные коды, рефералы и агенты.

Языки: [English](../README.md) · [فارسی](fa.md) · **Русский** · [中文](zh.md)

## Установка

Из панели (рекомендуется): **Сервисы → Дополнения → Каталог**, выберите **Nexora Shop**, ответьте на вопросы — и либо панель сама установит его на сервер по SSH, либо выдаст команду, которую вы запустите сами. Как только проверка состояния ответит, панель сама зарегистрирует Shop.

Вручную, на Linux-сервере, от root:

```sh
curl -fsSLO https://raw.githubusercontent.com/Nexora-VPN/shop/main/install.sh
sh install.sh --method script --opt port=8095 --panel-url https://your-panel --claim-code XXXX-XXXX-XXXX-XXXX
```

| Способ | Что запускается |
| --- | --- |
| `--method script` | исполняемый файл под юнитом systemd `nexora-addon-shop` |
| `--method docker` | compose-стек из [`deploy/compose.yml`](../deploy/compose.yml) (`ghcr.io/nexora-vpn/shop`) |

Всё хранится в `/opt/nexora-addons/shop`: ответы — в `.env`, данные — в `data/`.

- **Обновление:** снова запустите `sh install.sh` (или **Обновить на сервере** в панели). Ответы и данные сохраняются.
- **Удаление:** `sh install.sh --uninstall`, с `--purge` — вместе с данными.

| Параметр | По умолчанию | |
| --- | --- | --- |
| `port` | `8095` | порт, на котором слушает Shop |
| `database` | `sqlite` | `sqlite` держит всё в `data/`; `postgres` использует ваш собственный сервер |
| `database_dsn` | | строка подключения к PostgreSQL (спрашивается только для `postgres`) |
| `admin_username` | `admin` | собственная учётная запись администратора Shop |
| `admin_password` | | её пароль, не короче 10 символов; нужен один раз для создания учётной записи — потом смените его в самом Shop |
| `base_path` | случайный | путь, под которым работают админка Shop, её API и вызовы панели; страницы клиентов (`/app/`, `/pay/`) остаются в корне и никогда его не показывают. Панель и `install.sh` выбирают случайный; `base_path=` (пусто) ставит админку в корень. Обновление сохраняет то, что есть у установки |
| `https` | `off` | `acme`: сертификат для домена публичного адреса, на 443; `self-signed`: собственный сертификат Shop для адреса по IP (браузеры предупреждают, мини-приложение Telegram не открывается); `off`: без него или свой прокси |

Затем откройте админку Shop по её адресу и базовому пути — `install.sh` печатает его, панель открывает его из строки расширения — и пройдите шаги на странице **Настройка**: бот, публичный адрес, способ оплаты и первый товар.

## Языки клиентов

Shop говорит на персидском, английском, русском и китайском. В разделе **Настройки** включите те, на которых говорят ваши клиенты. Каждого клиента обслуживают на его языке — языке его Telegram или выбранном в боте либо веб-приложении, — если этот язык включён; иначе на английском или на первом включённом. Форма товара спрашивает название на каждом включённом языке; если название пустое, показывается название на другом языке. При выключении языка его клиенты переходят на ближайший включённый. Тексты бота можно переписать на каждом языке (**Тексты бота**).

## Напоминания, или уведомитель

По умолчанию Shop сам сообщает клиентам об их аккаунтах: шлёт свои напоминания перед окончанием срока и предупреждения панели — срок скоро истекает, срок истёк, трафик расходуется или закончился, аккаунт продлён или удалён в панели. Если у вас работает [уведомитель](https://github.com/Nexora-VPN/notif), который делает это для всех аккаунтов панели, выключите в разделе **Настройки** параметр **Магазин сообщает клиентам об окончании срока, трафике, продлении и удалении (выключите, если это делает уведомитель)**, чтобы никто не получал сообщения дважды. О том, что делает сам Shop, — покупке, чеке, кошельке, автопродлении, которое не удалось оплатить из кошелька, — по-прежнему сообщает Shop.

## Когда в панели нет места

Shop не проверяет собственную лицензию — это делает панель. Если панель отказывается создать новый аккаунт, потому что её лицензия исчерпана, Shop честно об этом говорит: деньги за заказ сразу возвращаются в кошелёк клиента, клиенту объясняют причину, в тему администраторов в Telegram уходит сообщение со словами самой панели, а продажа новых услуг и пробных периодов приостанавливается на час, чтобы следующие клиенты не наткнулись на тот же отказ. Продления и докупка трафика продолжают работать. Расширьте лицензию панели или освободите место, затем нажмите **Открыть продажи** на странице **Обзор**.

| Файл | Что это |
| --- | --- |
| [`nexora-addon.json`](../nexora-addon.json) | манифест, подписанный Nexora; каталог дополнений и панель читают его отсюда |

В релизах лежат исполняемые файлы для `linux-amd64` и `linux-arm64` с их `SHA256SUMS` и `SHA256SUMS.sig` — подписью Nexora над ним: панель ставит Shop по SSH, только если `install.sh` и исполняемый файл с ним совпадают. Shop бесплатный, с закрытым исходным кодом — см. [LICENSE](../LICENSE).

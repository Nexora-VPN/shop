# Nexora Shop

Официальное дополнение [Nexora](https://nexora-panel.org) для продажи тарифов панели: товары, заказы, кошелёк, платежи и Telegram-бот.

> **Этот выпуск — каркас.** Он устанавливается, регистрируется в панели, обновляется и удаляется точно так же, как будет работать Shop, но пока ничего не продаёт. Магазин появится в следующих выпусках.

## Установка

Из панели (рекомендуется): **Сервисы → Дополнения → Каталог**, выберите **Nexora Shop**, ответьте на вопросы и либо позвольте панели установить его на сервер по SSH, либо выполните команду, которую она покажет. Панель сама зарегистрирует Shop, как только ответит проверка работоспособности.

Вручную, на сервере Linux, от root:

```sh
curl -fsSLO https://raw.githubusercontent.com/Nexora-VPN/shop/main/install.sh
sh install.sh --method script --opt port=8095 --panel-url https://your-panel --claim-code XXXX-XXXX-XXXX-XXXX
```

| Способ | Что запускается |
| --- | --- |
| `--method script` | бинарный файл под юнитом systemd `nexora-addon-shop` |
| `--method docker` | стек compose из [`deploy/compose.yml`](../deploy/compose.yml) (`ghcr.io/nexora-vpn/shop`) |

Всё хранится в `/opt/nexora-addons/shop`: ответы в `.env`, данные в `data/`.

- **Обновление:** снова выполните `sh install.sh` (или «Обновить на сервере» в панели). Ответы и данные сохраняются.
- **Удаление:** `sh install.sh --uninstall`, с `--purge` удаляются и данные.

| Параметр | По умолчанию | |
| --- | --- | --- |
| `port` | `8095` | порт, на котором работает Shop |

Shop бесплатен и имеет закрытый код — см. [лицензию](../LICENSE).

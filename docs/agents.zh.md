# 代理

语言：[English](agents.md) · [فارسی](agents.fa.md) · [Русский](agents.ru.md) · **中文**

代理是您的一位做转售的客户：它用事先充值的钱包，按其**等级**的价格为自己的客户购买服务，并自己把每个链接交给客户。在管理后台的 **代理** 页面中设置。

## 等级

等级是一组代理的定价：

- **按百分比折扣**每个商品的商店价格；
- 为您指定的任意商品设置**专属价格**，取代百分比折扣；
- **推荐比例**：大于零时，代理的推荐链接按此比例从其带来的客户的每笔订单中给代理返利，取代商店的推荐百分比（商店的首单固定金额仍然适用——参见[优惠码和推荐](promotions.zh.md)）。

修改等级后，该等级下所有代理的价格从其下一笔订单起改变。仍有代理使用的等级不能删除。

## 设立代理

选择一位客户（已启动机器人或登录过网页应用的客户）、一个等级和一个**标签**——留空则使用客户名称。该客户立即成为代理；结束代理后它重新成为普通客户，钱包和服务都保留。

## 代理能做什么

- 在机器人中，菜单里有 **代理面板**：显示其等级、标签、钱包及最近的变动。列表显示的是它的价格；购买新服务时会询问**给哪位客户**（或 *不填名称*），服务列表中会以此名称标注每个服务。
- 在网页应用中，购买页面有同样的名称字段，价格是它自己的价格，钱包页面显示其等级和账单。
- 代理只能用钱包付款——不赊账；它像普通客户一样充值，或由您在代理页面为其钱包充值。
- 折扣码不适用于代理价格：等级就是它的折扣。
- 其服务的续费、加流量和自动续费也按它的价格计算。

## 在面板上

代理的客户不是 Shop 的客户：面板对他们一无所知。代理购买的每个账户都以代理的**标签**作为**分组**标记，因此在面板的用户页面上可以按代理筛选、统计和批量编辑其账户。（Shop 在账户创建后立即写入该标记；它会替换该账户上套餐自带的分组。）

## 账单

代理的账单（代理页面、机器人的代理面板、网页应用的钱包页面）读取自钱包本身的账本：每笔充值、购买、退款、支出、礼品和推荐奖励，以及每笔之后的余额——最后的余额就是钱包余额。

## API

| 路由 | 作用 |
| --- | --- |
| `GET`/`POST /api/agent-levels`, `PUT`/`DELETE /api/agent-levels/{id}` | 等级：`name`、`percent`、`prices`（`productId`、`currency`、`amount`）、`referralPercent` |
| `GET /api/agents` | 每个代理及其等级、钱包、服务和邀请的客户 |
| `PUT /api/agents/{customerId}` | 把客户设为代理，或调整：`levelId`、`tag` |
| `DELETE /api/agents/{customerId}` | 结束代理 |
| `GET /api/customers/{id}/statement` | 任意客户的账单（`?currency=`） |

面向客户：`GET /api/c/me` 包含 `agent`；`GET /api/c/products` 返回它的价格；`POST /api/c/orders` 接受 `label`；`GET /api/c/statement` 是它自己的账单。

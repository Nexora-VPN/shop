# 管理后台

语言：[English](admin.md) · [فارسی](admin.fa.md) · [Русский](admin.ru.md) · **中文**

Shop 的管理后台位于它自己的地址（`https://<shop>/`），提供英语、波斯语、俄语和中文界面。Shop 的一切操作都在这里完成，不需要 `curl`。

| 页面 | 用途 |
| --- | --- |
| **概览** | 今天和最近 30 天的销售额、等待人工审核的凭证、失败的订单、客户及其钱包余额；Shop 注册到的面板；因面板没有余量而暂停的新销售（[重新开放](zh.md)），与面板不一致的账户；以及当面板给客户的订阅链接带有其管理基础路径时的警告——只有面板自己的订阅基础路径（面板 **设置** 中的 **订阅基础路径**）能隐藏它；订阅域名或公开地址只改变主机，不改变路径 |
| **订单** | 每笔购买及买家和所购商品；把失败或已完成的订单退款到钱包，取消未支付的订单；面板调用已**停止**（太久无应答）的已付款订单可用**重新发送**再次发送——续费或流量须先确认面板上没有显示——或者退款 |
| **转账凭证** | 待批准或拒绝的卡对卡转账凭证（与 Telegram 话题中的队列相同） |
| **客户** | 按姓名、Telegram id、邮箱或电话查找客户；打开客户可编辑资料、为钱包充值或从钱包支出、查看账单、查看其服务，以及为其下单 |
| **代理** | 等级和代理（[代理](agents.zh.md)） |
| **报表** | 按时段和货币统计的销售额、新购与续费、续费率、热销商品和代理、折扣码、礼品码、推荐和退款的成本、钱包余额 |
| **商品** | 基于面板套餐的新服务、续费（按天数或自然月，可选流量和重置周期）、加流量；按货币定价；下架商品 |
| **支付方式** | 银行卡、通用网关及其健康状态、支付设置、银行短信转发器的地址和密钥、已收到的短信 |
| **优惠码** | 折扣码、礼品码、推荐奖励（[优惠码和推荐](promotions.zh.md)） |
| **机器人文案** | 机器人发送的每条消息，可按每种已开启的语言用您自己的话改写（见下文） |
| **设置** | 机器人（货币、试用、需先加入的频道、充值金额、客服、提醒、试用清理、自动续费）、客户语言、Shop 是否发送提醒（[或交给通知扩展](zh.md)）、发到管理员群组的消息语言、群发消息、邮件登录和短信登录 |
| **快速设置** | 让新 Shop 开始销售的检查清单（[网页应用](portal.zh.md)） |
| **安全** | 您的密码和两步登录 |
| **备份** | 备份计划、归档、密钥，以及面板恢复后的检查（[备份](backup.zh.md)） |

## 机器人文案

机器人的每条消息和每个按钮都可以按每种已开启的语言替换。文案是一个 Go 模板，使用该步骤提供的变量——编辑器下方以标签形式列出，如 `{{.Name}}`、`{{.Amount}}` 等——只能使用这些变量；编辑器会用示例值预览，Shop 保存前会进行检查，因此错误不会传到客户那里。保存后机器人立即使用新文案。清空文案或点击 **恢复内置**，会恢复 Shop 自带的措辞，后续版本可能会改进它。消息使用 Telegram 的 HTML：`<b>`、`<i>`、`<code>`、`<a href="…">`。

## 报表

**销售** 是指在所选时间段内付款且未退款的订单；试用不算销售。**续费率** 是指在该时间段之前售出的账户（不含试用，且仍在面板上）中，在该时间段内续费或加流量的比例。**钱包余额** 是商店当前欠客户的金额。金额按货币分别显示，从不换算。

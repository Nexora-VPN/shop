# Агенты

Языки: [English](agents.md) · [فارسی](agents.fa.md) · **Русский** · [中文](agents.zh.md)

Агент («نماینده») — это ваш клиент, который перепродаёт: он покупает услуги для своих клиентов по цене своего **уровня** из заранее пополненного кошелька и сам передаёт им каждую ссылку. Агенты настраиваются на странице **Агенты** в админке.

## Уровни

Уровень — это цена для группы агентов:

- **скидка в процентах** от цены магазина на каждый товар;
- **своя цена** на любой указанный вами товар — вместо процента;
- **реферальная ставка**: если она больше нуля, это то, что реферальная ссылка агента платит ему с каждого заказа приведённых им клиентов, вместо реферального процента магазина (фиксированная сумма магазина за первый заказ действует по-прежнему — см. [коды и рефералы](promotions.ru.md)).

Изменение уровня меняет цены всех его агентов начиная с их следующего заказа. Уровень, на котором есть хотя бы один агент, удалить нельзя.

## Как сделать агента

Выберите клиента (того, кто уже запускал бота или входил в веб-приложение), уровень и **метку** — если оставить её пустой, возьмётся имя клиента. Клиент сразу становится агентом; если прекратить агентство, он снова становится обычным клиентом, а его кошелёк и услуги остаются при нём.

## Что делает агент

- В боте в меню появляется **Кабинет агента**: уровень, метка, кошелёк и последние операции по нему. В списках показаны его цены; при покупке новой услуги бот спрашивает, **для какого клиента** она (или *Без имени*), и в списке услуг каждая подписана этим именем.
- В веб-приложении на странице покупки есть то же поле для имени, цены — его собственные, а на странице «Кошелёк» видны его уровень и выписка.
- Агент платит только из кошелька — в долг ничего не продаётся; он пополняет кошелёк как любой клиент, или вы зачисляете деньги на странице «Агенты».
- Промокоды на цену агента не действуют: его скидка — это уровень.
- Продления, докупка трафика и автопродление его услуг тоже идут по его цене.

## В панели

Клиенты агента — не клиенты Shop: панель о них ничего не узнаёт. Каждый аккаунт, купленный агентом, несёт **метку** агента в поле **группы** (group), поэтому на странице пользователей панели можно отфильтровать, посчитать и массово изменить аккаунты одного агента. (Shop записывает метку сразу после создания аккаунта; она заменяет группу тарифа на этом аккаунте.)

## Выписка

Выписка агента (страница «Агенты», кабинет агента в боте, страница «Кошелёк» в веб-приложении) читается из собственной книги кошелька: каждое пополнение, покупка, возврат, выплата, подарок и реферальная награда с остатком после каждой операции — последний остаток и есть кошелёк.

## API

| Маршрут | Что делает |
| --- | --- |
| `GET`/`POST /api/agent-levels`, `PUT`/`DELETE /api/agent-levels/{id}` | уровни: `name`, `percent`, `prices` (`productId`, `currency`, `amount`), `referralPercent` |
| `GET /api/agents` | все агенты с уровнем, кошельком, услугами и приглашёнными клиентами |
| `PUT /api/agents/{customerId}` | сделать клиента агентом или перевести на другой уровень: `levelId`, `tag` |
| `DELETE /api/agents/{customerId}` | прекратить агентство |
| `GET /api/customers/{id}/statement` | выписка любого клиента (`?currency=`) |

Для клиента: `GET /api/c/me` содержит `agent`; `GET /api/c/products` отдаёт его цены; `POST /api/c/orders` принимает `label`; `GET /api/c/statement` — его собственная выписка.
